Almanac.jl

Almanac.jl is a native Julia port of CSPICE N0067. It reads SPICE kernels and answers the questions CSPICE answers (where a body is, how a frame is oriented, when an event occurs) in pure Julia. Calls keep the CSPICE names, without the _c suffix, and with few exceptions the argument order; each docstring links to the NAIF page of the routine it ports.

Installation

pkg> add https://github.com/Orbitology/Almanac.jl

Julia 1.10 or later.

Features

  • Lock-free queries from any number of threads; each query reads an immutable snapshot of the loaded kernels.
  • Independent kernel sets, one per SpiceContext.
  • Time derivatives of any order (spkder, pxder) and dual-number epochs with ForwardDiff.jl.
  • Ephemeris and rotation tables for inner loops and GPU kernels.
  • Event searches, surface geometry on ellipsoids and DSK shapes, and writers for SPK, CK, binary PCK, DSK and EK files.
  • Bodies and frames defined by Julia functions (add_ephemeris!, add_frame!).

Use the wrapper SPICE.jl instead when results must be bit-identical to the CSPICE library on every platform.

Where to start

  • First session: load kernels, compute a state, a rotation and a sub-observer point, search for events.
  • Differences from CSPICE: read before porting a CSPICE or SPICE.jl program.
  • The how-to guides cover threads and contexts, derivatives, tables, user-defined bodies, event searches and writing kernels.

The examples run on three small kernels that the manual writes itself: leap seconds, constants of the Sun and the Earth with a spacecraft named PROBE, and two-body orbits of the Earth and of PROBE. Positions are therefore not those of the real bodies.

Contributing

Report defects and ask questions in the issues. Almanac.jl is not developed or supported by NAIF; do not send its defects to NAIF.
