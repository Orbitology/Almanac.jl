Almanac.jl

Almanac.jl is a native Julia port of CSPICE N0067, the C toolkit of NASA's NAIF for space geometry. It reads SPICE kernels and answers the questions CSPICE answers (where a body is, how a frame is oriented, when an event occurs) in pure Julia.

The calls keep the names of CSPICE without the _c suffix, and its argument order with few exceptions; the docstring of each ported call links to its NAIF page.

Installation

Almanac.jl needs Julia 1.10 or later. Install it from the Julia package manager:

pkg> add Almanac

Features

  • Queries from any number of threads without locks: each query reads an immutable snapshot of the loaded kernels.
  • Independent kernel sets, one per SpiceContext.
  • Event searches, surface geometry on ellipsoids and DSK shapes, and writers for SPK, CK, binary PCK, DSK and EK files.
  • Beyond CSPICE: time derivatives of any order and automatic differentiation, tables for inner loops and GPU kernels, bodies and frames defined by Julia functions, and orbital elements after ANISE, a Rust astrodynamics library. What Almanac.jl adds lists them all.

Use the wrapper SPICE.jl instead when results must be bit-identical to the CSPICE library on every platform.

The example kernels

The examples run on three small kernels that docs/fixture.jl of the repository writes: leap seconds, constants of the Sun and the Earth with the name of a spacecraft PROBE, and an SPK for the year 2025. The SPK holds the Sun at the solar system barycenter, the Earth on a two-body orbit around the Sun, and PROBE on a two-body orbit around the Earth, so the positions are not those of the real bodies.

Reporting issues

Report defects and ask questions in the issues. Almanac.jl is not developed or supported by NAIF, so do not send its defects to NAIF.
