First session

This session loads kernels, converts a time, computes a state and a rotation, finds the point below a spacecraft and searches for perigees. Names are those of CSPICE without _c; a call that changes an argument ends in !.

Load kernels

furnsh loads a kernel of any kind, including a meta-kernel; ktotal counts loaded kernels. Here kernels holds three paths: leap seconds, constants of the Sun and the Earth, and an SPK.

using Almanac

foreach(furnsh, kernels)
ktotal("ALL")
3

As in CSPICE, relative paths in a meta-kernel's KERNELS_TO_LOAD are relative to the working directory, not to the meta-kernel; use PATH_SYMBOLS and PATH_VALUES for anything else.

For real bodies, SPICEKernels.jl downloads the NAIF generic kernels and returns their paths:

using SPICEKernels

furnsh(naif0012_tls())   # leap seconds
furnsh(de440s())         # planets, Moon and Sun, 1849 to 2150
furnsh(pck00011())       # orientation and radii of the bodies

Convert a time

State, frame, geometry and event calls take epochs in seconds past J2000 TDB (ET); the CK calls take encoded spacecraft clock. str2et parses a calendar string and timout formats an epoch with a picture string.

et = str2et("2025 MAR 01 12:00:00 UTC")
7.941024691853893e8
timout(et, "YYYY Mon DD HR:MN:SC.### ::TDB")
"2025 Mar 01 12:01:09.185"

The 69.185 s offset is TDB − UTC at that date.

State of a body

spkezr returns the state of a target relative to an observer (km, km/s) and the one-way light time (s). "NONE" gives the geometric state, "LT+S" the apparent one.

state, lt = spkezr("PROBE", et, "J2000", "NONE", "EARTH")
state
6-element StaticArraysCore.SVector{6, Float64} with indices SOneTo(6):
 -25386.153654167378
   3798.1095549445336
  10439.640397850508
      1.6495610692719271
     -2.653083994095216
     -1.6791978258568458

The state is an SVector{6}. The call does not allocate when bodies and frame are integer IDs or upper-case names with single blanks ("MARS BARYCENTER"). spkpos returns the position only:

sun, lt_sun = spkpos("SUN", et, "J2000", "LT+S", "PROBE")
lt_sun                        # s
499.09303254200233

Rotation between frames

pxform returns the 3×3 rotation from one frame to another, sxform the 6×6 state transformation.

r = pxform("J2000", "IAU_EARTH", et)
r * state[1:3]                # km, in the Earth-fixed frame
3-element StaticArraysCore.SVector{3, Float64} with indices SOneTo(3):
 -25098.479950465102
  -5499.336364979118
  10377.481818905228

The point below the spacecraft

subpnt returns the sub-observer point in the body-fixed frame, the epoch at the target and the observer-to-point vector. reclat converts it to radius, longitude and latitude (rad).

point, epoch, vector = subpnt("NEAR POINT/ELLIPSOID", "EARTH", et, "IAU_EARTH", "NONE", "PROBE")
radius, lon, lat = reclat(point)
(lon * dpr(), lat * dpr())    # degrees
(-167.64121130971648, 21.89048118925036)

Search for an event

The gf calls search a Window of time for the epochs where a quantity meets a condition, and return a Window. Below, the local minima of the distance over one day. The arguments after the relation are the reference value and the adjustment (both unused for "LOCMIN") and the step, 600 s; The step says how to choose it.

search = Window()
wninsd!(search, et, et + 86400.0)
perigees = gfdist("PROBE", "NONE", "EARTH", "LOCMIN", 0.0, 0.0, 600.0, search)

for i in 1:wncard(perigees)
    t, _ = wnfetd(perigees, i)
    distance = vnorm(spkpos("PROBE", t, "J2000", "NONE", "EARTH")[1])
    println(timout(t, "YYYY Mon DD HR:MN:SC ::TDB"), "   ", round(distance; digits=3), " km")
end
2025 Mar 01 13:47:52   7078.137 km
2025 Mar 02 00:28:40   7078.137 km
2025 Mar 02 11:09:28   7078.137 km

The example orbit has a perigee radius of 7078.137 km.

Unload

kclear removes all kernels; unload removes one file, or a meta-kernel and the files it loaded.

kclear()
ktotal("ALL")
0

Errors

A call that cannot answer throws a SpiceError, usually its subtype SpiceKindError. Its kind is the CSPICE short message as a lower-case symbol (SPICE(IDCODENOTFOUND) becomes :idcodenotfound), and msg the text.

try
    spkezr("PROBE", et, "J2000", "NONE", "EARTH")
catch err
    err.kind
end
:idcodenotfound

Missing SPK data throw the subtype SpkInsufficientDataError, whose fields name the bodies, the epoch, and whether the missing body has data at other epochs.

Before porting a CSPICE program, read Differences from CSPICE.
