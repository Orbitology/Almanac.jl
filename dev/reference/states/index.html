States and aberration

Positions and states

Almanac.spkezr — Function
spkezr([ctx,] targ, et, ref, abcorr, obs) -> (state, lt)

Return the state of targ relative to obs in frame ref at et, and the one-way light time, as spkezr_c.

state is an SVector{6}: position in km, then velocity in km/s. lt is in seconds.

  • targ, obs: body name, NAIF ID code, or a string that holds a code ("-77").
  • et: epoch of the observer in seconds past J2000 TDB (see str2et).
  • ref: frame name or frame ID. For a frame that is not inertial and a correction other than "NONE", the frame is evaluated at et corrected for the light time between the observer and the frame center, as in CSPICE.
  • abcorr: "NONE" (geometric), "LT", "LT+S", "CN", "CN+S" for reception, or the same with the prefix X for transmission. Letter case and blanks are ignored. An Aberration value is also accepted.

The call does not allocate, with integer IDs or with names in any case, unless it throws or a chain has more than 10 SPK segments. With ForwardDiff loaded, et can be a dual number (see Differentiate with ForwardDiff).

The SPK segments connect a body to its center, and that center to the next one. The call needs such a chain from targ and from obs to a common body.

Throws SpiceError:

  • :idcodenotfound if a body name is not known, :unknownframe if a frame name is not known;
  • :invalidoption if abcorr is not valid, :badarg if et is not finite;
  • :noloadedfiles if no SPK file is loaded;
  • :spkinsuffdata if the loaded SPK files hold no chain between targ and obs at the epoch needed: a body is in no file, or the epoch is outside its segments;
  • the kinds of pxform if ref is not inertial and its orientation data are not loaded.

:noloadedfiles and :spkinsuffdata are a SpkInsufficientDataError, which holds the body and the epoch.

Examples

furnsh("naif0012.tls")
furnsh("de440s.bsp")
et = str2et("2025-03-01T12:00:00")
state, lt = spkezr("MARS BARYCENTER", et, "ECLIPJ2000", "LT+S", "EARTH")
r, v = state[1:3], state[4:6]                  # km, km/s
state, lt = spkezr(4, et, 17, Aberration("LT+S"), 399)   # the same with IDs

See also spkpos, spkgeo, spkder, furnsh.

Almanac.spkpos — Function
spkpos([ctx,] targ, et, ref, abcorr, obs) -> (pos, lt)

Return the position of targ relative to obs in frame ref at et, and the one-way light time, as spkpos_c.

pos is an SVector{3} in km and lt is in seconds. The arguments and the errors are those of spkezr, except that an abcorr that is not valid throws SpiceError(:spkinvalidoption), as in CSPICE.

As in CSPICE, the CN corrections make three light-time iterations here; spkezr makes up to five, with the convergence test of spkltc. The position can therefore differ from the position part of spkezr by up to 2e-11 relative (see Known limits of accuracy).

Examples

et = str2et("2025-03-01T12:00:00")
pos, lt = spkpos("SUN", et, "J2000", "LT+S", "EARTH")    # km, s

See also spkezr, spkder.

spkgeo([ctx,] targ::Integer, et, ref, obs::Integer) -> (state, lt)

Derivatives of any order

Almanac.spkder — Function
spkder([ctx,] targ, et, ref, obs, Val(N)) -> NTuple{N+1,SVector{3}}
spkder([ctx,] targ, et, ref, abcorr, obs, Val(N)) -> NTuple{N+1,SVector{3}}

Return the position of targ relative to obs in frame ref at et and its time derivatives to order N. This call has no CSPICE counterpart.

Element k + 1 of the result is the derivative of order k, in km/s^k. et is in seconds past J2000 TDB. targ, obs and ref are names or integer IDs. The form without abcorr is geometric, as is abcorr = "NONE"; abcorr is a string or an Aberration, as for spkezr. With ForwardDiff loaded, et can be a dual number. The call does not allocate under the condition that spkezr states.

Order 0 is the position of spkezr and of spkpos, to rounding. Every higher order is the exact derivative of that position as a function of et, and agrees with a finite difference of spkpos. The exception is an SPK segment that stores the velocity apart from the position (for example types 3 and 9): there order 1 is the stored velocity and the higher orders are its derivatives. A dual-number epoch gives the same derivatives as this call.

Order 1 is the velocity of spkezr for a geometric state. With an LT correction it differs from that velocity, by about 1e-8 relative for the Moon seen from the Earth, because CSPICE approximates the rate of the light time. Derivatives and stored rates gives the function that is differentiated.

Throws SpiceError(:badarg) if N is not an integer >= 0, SpiceError(:invalidoption) if abcorr is not valid, and the errors of spkezr.

Examples

et = str2et("2025-03-01T12:00:00")
r, v, a = spkder("MOON", et, "J2000", "EARTH", Val(2))          # km, km/s, km/s^2
r, v, a, j = spkder("MOON", et, "J2000", "LT+S", "EARTH", Val(3))

See also pxder, spkezr.

Almanac.pxder — Function
pxder([ctx,] from, to, et, Val(N)) -> NTuple{N+1,SMatrix{3,3}}

Return the rotation matrix from frame from to frame to at et and its time derivatives to order N. This call has no CSPICE counterpart.

Element k + 1 of the result is the derivative of order k, in 1/s^k. The arguments from, to and et are those of pxform. Order 0 is the matrix of pxform, and every higher order is the exact derivative of that matrix as a function of et.

Order 1 is the derivative block of sxform, except for the following frames, where it can differ because sxform follows the rates of CSPICE:

  • CK frames (class 3);
  • dynamic frames (class 5) of the true equator and equinox of date, two-vector frames, and frames defined with ROTATION_STATE = 'INERTIAL';
  • switch frames (class 6), which take a base frame by epoch, where the base is one of the above.

Derivatives and stored rates says what is differentiated for each class.

Throws SpiceError(:badarg) if N is not an integer >= 0, and the errors of pxform.

Examples

julia> R, dR = pxder("J2000", "ECLIPJ2000", 0.0, Val(1));

julia> iszero(dR)    # two inertial frames
true

See also spkder.

Aberration corrections

Almanac.Aberration — Type
Aberration(abcorr::AbstractString)
Aberration(; uselt=false, converged=false, stellar=false, transmit=false)

An aberration correction as an isbits value. Every call that takes a correction string also takes an Aberration; the string is then not parsed at each call.

StringCorrection
"NONE"none: the geometric state
"LT"reception, one-way light time, one iteration
"LT+S""LT" and stellar aberration
"CN"reception, light time iterated to convergence
"CN+S""CN" and stellar aberration
"XLT", "XLT+S"the "LT" forms for transmission
"XCN", "XCN+S"the "CN" forms for transmission

Reception gives the target as the observer sees it at et: the target at et - lt. Transmission gives the target where a signal sent at et reaches it: the target at et + lt. Letter case and blanks in the string are ignored.

The keyword form builds the value from flags; converged, stellar and transmit each imply uselt, the light-time correction. A value c has the properties c.uselt, c.converged, c.stellar, c.transmit and c.geometric (true for "NONE" only). string(c) gives the CSPICE spelling.

Throws SpiceError(:invalidoption) if the string is not one of the nine above, including the values that CSPICE recognizes and rejects: RL, RL+S, XRL, XRL+S, S, XS.

Examples

julia> c = Aberration(" lt + s ")
Aberration("LT+S")

julia> c.stellar, c.transmit, c.geometric
(true, false, false)

julia> Aberration(converged=true, transmit=true)
Aberration("XCN")

See also spkezr, spkpos.

Almanac.spkltc — Function
spkltc([ctx,] targ::Integer, et, ref, abcorr, stobs) -> (state, lt, dlt)

Return the state of body targ relative to an observer with a given barycentric state, corrected for light time, with the light time and its rate, as spkltc_c.

  • et: epoch of the observer in seconds past J2000 TDB.
  • stobs: state of the observer relative to the solar system barycenter at et, in ref; 6 elements, km and km/s.
  • ref: an inertial frame, by name or ID.
  • abcorr: as for spkezr. Stellar aberration is not applied, whatever abcorr says.

state is an SVector{6} in km and km/s, lt is in seconds and dlt is the time derivative of lt (no unit). The LT forms make one iteration. The CN forms make at most five and stop when the light time changes by less than 1e-17 * max(1, |epoch|).

Throws SpiceError:

  • :invalidoption if abcorr is not valid (checked first, as in CSPICE);
  • :badframe if ref is not inertial;
  • :badarg if stobs does not have 6 elements or et is not finite;
  • :dividebyzero if the range rate of the target is above (1 - 1e-10) times the speed of light;
  • the SPK errors of spkgeo.

See also spkaps, spkacs.

Prepared state queries

Almanac.state_query — Function
state_query([ctx,] targ, ref, abcorr, obs) -> StateQuery

Resolve the names of the target targ and the observer obs, the frame ref and the aberration correction abcorr once, for a state that a program needs at many epochs. The arguments are those of spkezr without the epoch, in the same order.

The query holds the kernels of ctx as they are at the call: a later furnsh, unload or pool edit of ctx does not change it. The query is immutable, so one query can be used from any number of threads.

spkezr(q, et) and spkpos(q, et) return what spkezr and spkpos return for the same arguments and kernels, to the last bit, without the lookup of the names at each epoch. The epoch can be a ForwardDiff.Dual, as for spkezr. This call has no CSPICE counterpart.

Throws SpiceError:

  • :idcodenotfound if targ or obs is not a known body name;
  • :unknownframe if ref is not a known frame;
  • the kinds of Aberration for a malformed abcorr.

Data that is missing for an epoch throws at the evaluation, as spkezr does.

Examples

julia> ctx = SpiceContext();

julia> add_ephemeris!(et -> [7000.0, 0.001et, 0, 0, 0.001, 0], ctx, -1000, 399, "J2000", 0.0, 100.0)

julia> q = state_query(ctx, -1000, "J2000", "NONE", 399);

julia> q(50.0)[1] == spkezr(ctx, -1000, 50.0, "J2000", "NONE", 399)[1]
true

See also rotation_query.

Bodies defined by Julia functions

Almanac.add_ephemeris! — Function
add_ephemeris!(f, [ctx,] body, center, frame, t0, t1; name="", bodies=()) -> Nothing

Make body a body whose state relative to center in frame is f(et) for t0 <= et <= t1 (ET, seconds past J2000 TDB). f returns six numbers: the position (km) and the velocity (km/s).

The body is then available to every call that reads SPK data. It enters the load list as a file named name with one SPK segment, so the rules of a file hold: it has priority over the files loaded before it, outside [t0, t1] the files that cover the body apply, and unload with name removes it. An empty name stands for "ephemeris of body <code>", with the NAIF code of body.

bodies, pairs such as ["MYSAT" => -1001], are body names that hold while the provider is loaded, as for furnsh of a handle; body and center may be one of them.

f is called from any thread that makes a query, so it must not change shared data. It receives the epoch type of the query: Float64, a ForwardDiff.Dual for a dual-number epoch, and for a derivative of order 2 or more (the acceleration that an LT+S state of an observer needs, spkder) a Taylor number of this package, on which f may use arithmetic and the functions of Base but no comparison. f may query ctx for other bodies, but not for body in the interval it covers.

body and center are NAIF codes or names, and frame a frame name or code, all known to ctx at the call. This call has no CSPICE counterpart.

Throws SpiceError:

  • :idcodenotfound for an unknown body or center name;
  • :unknownframe for an unknown frame;
  • :baddescrtimes if t1 < t0;
  • :barycenterephem if body and center are the same body.

A query throws SpiceError(:badarraysize) if f returns something other than six numbers.

Examples

julia> ctx = SpiceContext();

julia> add_ephemeris!(ctx, -1000, 399, "J2000", 0.0, 3600.0) do et
           [7000.0 + 0.001et, 0.0, 0.0, 0.001, 0.0, 0.0]
       end

julia> spkezr(ctx, -1000, 60.0, "J2000", "NONE", 399)[1] ≈ [7000.06, 0, 0, 0.001, 0, 0]
true

See also unload, ephemeris_table.

Almanac.load_samples! — Function
load_samples!([ctx,] name, body, center, frame, ets, states;
              method=:hermite, degree=7, segid=name, bodies=()) -> Nothing

Load the states states (km, km/s) of body relative to center in frame at the epochs ets (seconds past J2000 TDB, increasing) into ctx as a kernel named name, with no file; queries interpolate between them. This call has no CSPICE counterpart.

The kernel holds one SPK segment from ets[1] to ets[end]: type 13 (Hermite interpolation, which uses the velocities) for method = :hermite, type 9 (Lagrange interpolation) for :lagrange, with polynomials of degree degree. Type 13 needs an odd degree in 1:27 and at least (degree + 1) ÷ 2 states; type 9 a degree in 1:27 and more than degree states. states is a 6 by n matrix, a vector of 6-vectors, or a flat vector, as for spkw13. The kernel is the one that spkw13 or spkw09 writes to a file, so queries give the same results as on that file. segid is cut to its first 40 characters. bodies are body names of the kernel, as for furnsh of a handle; body and center are NAIF codes or names, and may be names of bodies. A trajectory with jumps (burns) needs one call per arc.

Throws SpiceError:

  • :emptystring or :blankfilename if name is empty or blank;
  • :invalidargument if method is not :hermite or :lagrange;
  • :toofewstates if ets is empty;
  • :idcodenotfound for an unknown body name;
  • the errors of spkw13 or spkw09 (degree, order of the epochs, ...).

A call that throws leaves ctx unchanged.

Examples

julia> ctx = SpiceContext();

julia> ets = [0.0, 60.0, 120.0];

julia> states = [[7000.0 + 0.5t, 0, 0, 0.5, 0, 0] for t in ets];

julia> load_samples!(ctx, "probe", "PROBE", 399, "J2000", ets, states; degree = 3,
                     bodies = ["PROBE" => -1000])

julia> spkpos(ctx, "PROBE", 30.0, "J2000", "NONE", "EARTH")[1] ≈ [7015.0, 0, 0]
true

See also load_function!, furnsh, spkops.

Almanac.load_function! — Function
load_function!([ctx,] name, f, body, center, frame, t0, t1;
               tol=nothing, ncoef=16, maxintervals=65536, segid=name, bodies=())
    -> (poserr, velerr)

Fit the trajectory f(et) of body relative to center in frame on t0 <= et <= t1 (seconds past J2000 TDB) with Chebyshev polynomials, and load the fit into ctx as a kernel named name, with no file. f is called with Float64 epochs, on the calling task, during the call only, so a query costs what a query of an SPK file costs. This call has no CSPICE counterpart.

f returns six numbers, the position (km) and the velocity (km/s), or three, the position only. With six the kernel has an SPK segment of type 3 (a series for the position and one for the velocity); with three, of type 2 (the velocity is the derivative of the position). The fit takes ncoef coefficients on each of n intervals of equal length and doubles n until the position error is at most tol (km). Without tol the goal is 1e-12 times the largest distance, with the early stop of ephemeris_table. The result is the measured largest position error (km) and velocity error (km/s, NaN for three numbers). body, center, segid and bodies are as for load_samples!.

An ODESolution goes in through a closure; see Kernels in memory.

Throws SpiceError:

  • :emptystring or :blankfilename if name is empty or blank;
  • :badarg unless t0 < t1 are finite, 2 <= ncoef <= 28, tol > 0 and maxintervals >= 1;
  • :badarraysize if f returns something other than three or six numbers;
  • :noconvergence if maxintervals intervals do not reach the tolerance;
  • :idcodenotfound for an unknown body name, and the errors of f.

A call that throws leaves ctx unchanged.

Examples

julia> ctx = SpiceContext();

julia> gm, pv0 = 398600.4418, [7000.0, 0, 0, 0, 7.5, 1.0];

julia> poserr, velerr = load_function!(ctx, "orbit", et -> prop2b(gm, pv0, et), -1000, 399,
                                        "J2000", 0.0, 86400.0; tol = 1e-6);

julia> poserr <= 1e-6
true

julia> vnorm(spkpos(ctx, -1000, 5000.0, "J2000", "NONE", 399)[1] - prop2b(gm, pv0, 5000.0)[1:3]) <= 1e-6
true

See also load_samples!, ephemeris_table, add_ephemeris!.

EphemerisTable{T,A<:AbstractVector{T}}
EphemerisTable(coef, t0, dt, nint, ncoef, target, observer, frame, maxerr)
EphemerisTable{T}(tab) -> EphemerisTable{T,Vector{T}}

Position of one body relative to another on a fixed span of time, as piecewise Chebyshev polynomials that need no kernel to evaluate. ephemeris_table makes one; the constructor with nine arguments takes the fields of the table below.

A query does no segment search and follows no chain of bodies, so it suits the inner loop of an optimizer. With Adapt.jl loaded, adapt moves the coefficients to another array type; the table is then an isbits value on a GPU.

coefthe coefficients, km
maxerrlargest difference from spkpos that ephemeris_table measured, km

Almanac.ephemeris_table — Function
ephemeris_table([ctx,] targ, t0, t1, ref, abcorr, obs;
                tol=nothing, ncoef=16, maxintervals=65536) -> EphemerisTable

Return a table of the position of targ relative to obs in frame ref for t0 <= et <= t1, which table_position, table_state and table_jet evaluate without the kernels. This call has no CSPICE counterpart.

t0 and t1 are in seconds past J2000 TDB. targ, ref, abcorr and obs are as for spkpos. The table is a snapshot: a later change of the kernels does not change it. The result is an EphemerisTable{Float64,Vector{Float64}}, and its field maxerr is the measured error in km.

Two methods give the coefficients:

  • Records of the kernels. If abcorr is "NONE", ref is inertial, and every segment between the two bodies is SPK type 2 in an inertial frame with record boundaries on one common grid, the table takes the record length and the degree of the kernels. It then agrees with spkpos to rounding, and tol, ncoef and maxintervals are not used. The table covers whole records of the shortest record length, at least t0 to t1: it can start up to one record before t0 and end up to one record after t1, and a query in that margin does not throw.
  • Interpolation. In all other cases the call interpolates on t0 to t1 with ncoef coefficients for each interval, and it doubles the number of intervals until the measured error is at most tol (km). With tol, the result has maxerr <= tol or the call throws. Without tol the goal is 1e-12 times the largest distance in the table, and the call also stops when the error is below 1e-6 times that distance and one more doubling does not divide it by four. spkpos then limits the accuracy: rounding of a rotation angle of many turns, or the small steps of an aberration-corrected position at the record boundaries.

Throws SpiceError(:badarg) if the epochs are not finite with t0 < t1, if ncoef < 2, tol <= 0 or maxintervals < 1. Throws SpiceError(:noconvergence) if maxintervals intervals do not reach the goal, and the errors of spkpos if the kernels do not cover t0 to t1.

Examples

furnsh("naif0012.tls"); furnsh("de440s.bsp")
t0, t1 = str2et("2025-01-01"), str2et("2026-01-01")
tab = ephemeris_table("MARS BARYCENTER", t0, t1, "ECLIPJ2000", "NONE", "SUN")
tab.maxerr                              # km
r = table_position(tab, t0 + 86400.0)   # km, no kernel access
x = table_state(tab, t0 + 86400.0)      # km, km/s
tab32 = EphemerisTable{Float32}(tab)    # smaller, about seven digits

See also EphemerisTable, rotation_table, table_to_spk.

Almanac.table_jet — Function
table_jet(tab, et, Val(N)) -> NTuple{N+1,SVector{3}}

Return the position from the ephemeris table tab at et, in km, and its time derivatives to order N.

Element k + 1 is the derivative of order k, in km/s^k; every order is a derivative of the position polynomial. et is in seconds past J2000 TDB and is a plain number or a dual number. Almanac.table_span — Function
table_span(tab) -> (first, last)

Return the first and the last epoch of the table tab, in seconds past J2000 TDB.

tab is an EphemerisTable or a RotationTable. A query is valid for first <= et <= last. A table that ephemeris_table or rotation_table made covers at least the requested t0 to t1; one made from the records of the kernels covers whole records, so its span can be wider.

Almanac.rotation_table — Function
rotation_table([ctx,] from, to, t0, t1; tol=nothing, ncoef=16, maxintervals=65536)
    -> RotationTable

Return a table of the rotation from frame from to frame to for t0 <= et <= t1, which table_rotation and table_rotation_jet evaluate without the kernels. This call has no CSPICE counterpart.

t0 and t1 are in seconds past J2000 TDB; the frames are as for pxform. The result is a RotationTable{Float64,Vector{Float64}} with table_span(result) == (t0, t1) to rounding, and its field maxerr is the measured error.

The call interpolates the nine elements of the matrix with ncoef coefficients for each interval, and it doubles the number of intervals until the measured error (Frobenius norm, no unit) is at most tol. With tol, the result has maxerr <= tol or the call throws. Without tol the goal is 1.7e-12, and the call also stops when the error is below 1.7e-6 and one more doubling does not divide it by four. pxform then limits the accuracy: the rotation angle of many turns has a rounding error above the goal. Read maxerr for the error that was reached.

Throws SpiceError(:badarg) if the epochs are not finite with t0 < t1, if ncoef < 2, tol <= 0 or maxintervals < 1. Throws SpiceError(:noconvergence) if maxintervals intervals do not reach the goal, and the errors of pxform if the kernels do not cover t0 to t1.

Almanac.table_to_spk — Function
table_to_spk([ctx,] handle, tab, segid; first=table_span(tab)[1],
             last=table_span(tab)[2]) -> Nothing

Add the ephemeris table tab to the SPK file handle as one segment of type 2.

The records of the table are the records of the segment. spkpos on the new file therefore gives the position of the table to rounding, and the velocity is its derivative. handle comes from spkopn, spkopa or spkops; segid is the segment identifier; first and last are the bounds of the segment in seconds past J2000 TDB. The segment is for tab.target relative to tab.observer in the frame tab.frame, which must be a frame known in ctx (default: the default context; see frinfo). The coefficients are written as Float64; a table on a GPU is copied to the CPU.

A segment has no aberration correction. Write only a table that was made with abcorr = "NONE"; the call cannot check this.

Throws SpiceError(:invalidrefframe) if tab.frame is not a frame of ctx, as spkw02_c for an unknown frame, and the other errors of spkw02. Among its conditions: tab.ncoef <= 28, and first and last inside the table.

Examples

tab = ephemeris_table("MOON", t0, t1, "J2000", "NONE", "EARTH")
h = spkopn("moon.bsp", "moon.bsp", 0)
table_to_spk(h, tab, "Moon from table")
spkcls(h)
