Coordinates

The rules for all mathematics calls hold on this page.

Coordinate conversions

Almanac.reclat — Function
reclat(rectan) -> (radius, lon, lat)

Return the latitudinal coordinates of the rectangular point rectan, as reclat_c of CSPICE.

radius has the unit of rectan. The angles are in radians: the longitude lon in (-pi, pi], from the x axis toward the y axis, and the latitude lat in [-pi/2, pi/2], from the xy plane. lon is 0 on the z axis, and all three are 0 at the origin.

Throws SpiceError(:badarg) if rectan does not have 3 elements.

Examples

julia> reclat([0, 2, 0])
(2.0, 1.5707963267948966, 0.0)

julia> latrec(2, pi / 2, 0) ≈ [0, 2, 0]
true

See also latrec, recrad, recsph, recgeo, dlatdr.

Almanac.recrad — Function
recrad(rectan) -> (range, ra, dec)

Return the range, the right ascension and the declination of the rectangular point rectan, as recrad_c of CSPICE.

The angles are in radians: ra in [0, 2 pi) and dec in [-pi/2, pi/2]. They differ from the result of reclat only in the range of the first angle.

Throws SpiceError(:badarg) if rectan does not have 3 elements.

Examples

julia> recrad([0, -2, 0])
(2.0, 4.71238898038469, 0.0)

See also radrec, reclat.

Almanac.recgeo — Function
recgeo(rectan, re, f) -> (lon, lat, alt)

Return the geodetic coordinates of the rectangular point rectan relative to a spheroid, as recgeo_c of CSPICE.

The spheroid has the equatorial radius re and the flattening f; its polar radius is re * (1 - f). lon and lat are in radians. lat is the angle between the equatorial plane and the outward normal at the surface point nearest to rectan, which nearpt finds. alt is the height above that point, in the unit of re and rectan; it is negative inside the spheroid. lon is in (-pi, pi], and it is 0 on the z axis.

Throws SpiceError(:valueoutofrange) if re <= 0 or f >= 1, and SpiceError(:badarg) if rectan does not have 3 elements.

Examples

A point 100 km above the equator of the WGS 84 spheroid:

julia> re, f = 6378.137, 1 / 298.257223563;

julia> round.(recgeo([0, 6478.137, 0], re, f); digits=6)
(1.570796, 0.0, 100.0)

julia> georec(pi / 2, 0, 100, re, f) ≈ [0, 6478.137, 0]
true

See also georec, recpgr, dgeodr.

Almanac.recpgr — Function
recpgr([ctx,] body, rectan, re, f) -> (lon, lat, alt)

Return the planetographic coordinates of the rectangular point rectan relative to the spheroid of body, as recpgr_c of CSPICE.

body is a name or an ID. re is the equatorial radius and f the flattening of the spheroid. lat (radians) and alt are the geodetic values of recgeo. lon is in radians in [0, 2 pi]; a longitude just below zero can round to 2 pi. Its sense comes from the kernel pool of ctx, or of default_context without ctx, by the first rule that applies:

  1. The variable BODY<id>_PGR_POSITIVE_LON (EAST or WEST) gives the sense, for every body.
  2. For the Earth the longitude is positive east.
  3. For another body the prime meridian BODY<id>_PM must be in the pool. For the Moon and the Sun the longitude is then positive east. For the other bodies it is positive west for prograde rotation (the rate BODY<id>_PM[2] is positive) and positive east for retrograde rotation.

Throws:

  • SpiceError(:idcodenotfound) if body is a name without an ID.
  • SpiceError(:valueoutofrange) if re <= 0 or f >= 1.
  • SpiceError(:invalidoption) if the sense variable is not EAST or WEST.
  • SpiceError(:missingdata) if body is not the Earth and the sense variable and BODY<id>_PM are both absent.

Examples

julia> ctx = SpiceContext();

julia> pcpool(ctx, "BODY499_PGR_POSITIVE_LON", ["WEST"]);

julia> round.(recpgr(ctx, "MARS", [0, 3496.19, 0], 3396.19, 0.00589); digits=6)
(4.712389, 0.0, 100.0)

julia> pgrrec(ctx, "MARS", 3pi / 2, 0, 100, 3396.19, 0.00589) ≈ [0, 3496.19, 0]
true

See also pgrrec, recgeo, dpgrdr.

Almanac.xfmsta — Function
xfmsta([ctx,] istate, icosys, ocosys, body) -> SVector{6}

Return the state istate converted from the coordinate system icosys to the coordinate system ocosys, as xfmsta_c of CSPICE.

A state is three coordinates followed by their time derivatives. The names of the systems ignore case and blanks. Angles are in radians. A length has the unit of the input; with "GEODETIC" or "PLANETOGRAPHIC" it is in km, the unit of the radii.

SystemCoordinates
"RECTANGULAR"x, y, z
"CYLINDRICAL"distance from the z axis, lon, z
"LATITUDINAL"distance from the origin, lon, lat
"SPHERICAL"distance from the origin, colat, lon
"GEODETIC"lon, lat, alt
"PLANETOGRAPHIC"lon, lat, alt

body (name or ID) gives the spheroid of the last two systems, from BODY<id>_RADII in the kernel pool of ctx, or of default_context without ctx. It is not read for the other systems, so "" is enough there. Each output longitude has the range of the conversion from rectangular coordinates to its system, such as reccyl; the planetographic one also throws the errors of recpgr.

Throws:

  • SpiceError(:coordsysnotrec) if a system name is not known.
  • SpiceError(:idcodenotfound) if body is needed and is a name without an ID.
  • SpiceError(:kernelvarnotfound) if body is needed and has no radii in the pool.
  • SpiceError(:notsupported) if the first two radii of body differ.
  • SpiceError(:invalidstate) if the position is on the z axis and the velocity is not along it; the output rates are then not defined.
  • SpiceError(:numericoverflow) if a velocity component would overflow.
  • SpiceError(:badarg) if istate does not have 6 elements.

Examples

A point on the x axis that moves along y has a longitude rate:

julia> s = xfmsta([2, 0, 0, 0, 1, 0], "RECTANGULAR", "LATITUDINAL", "");

julia> s == [2, 0, 0, 0, 0.5, 0]
true

See also reclat, recgeo, recpgr, dlatdr.

Almanac.convrt — Function
convrt(x, in, out)

Return the measurement x converted from the unit in to the unit out, as convrt_c of CSPICE.

ClassUnits
angleRADIANS, DEGREES, ARCMINUTES, ARCSECONDS, HOURANGLE, MINUTEANGLE, SECONDANGLE
distanceMETERS, M, KILOMETERS, KM, CENTIMETERS, CM, MILLIMETERS, MM, FEET, INCHES, YARDS, STATUTE_MILES, NAUTICAL_MILES, AU, LIGHTSECS, LIGHTYEARS, PARSECS
timeSECONDS, MINUTES, HOURS, DAYS, JULIAN_YEARS, TROPICAL_YEARS, YEARS

The names ignore case and trailing blanks. YEARS is JULIAN_YEARS.

Throws SpiceError(:unitsnotrec) if a unit is not known, and SpiceError(:incompatibleunits) if the two units are of different classes.

Examples

julia> convrt(1.5, "HOURS", "MINUTES")
90.0

julia> convrt(1, "km", "METERS")
1000.0

Jacobians of coordinate conversions

Element [i, j] of each Jacobian is the derivative of output coordinate i with respect to input coordinate j. Angles are in radians.

Almanac.drdlat — Function
drdlat(r, lon, lat) -> SMatrix{3,3}

Return the Jacobian of rectangular coordinates with respect to the latitudinal coordinates (r, lon, lat), as drdlat_c of CSPICE.

See also dlatdr, latrec.

source
Almanac.dlatdr — Function
dlatdr(x, y, z) -> SMatrix{3,3}

Return the Jacobian of the latitudinal coordinates (radius, lon, lat) with respect to rectangular coordinates, at the point (x, y, z), as dlatdr_c of CSPICE.

Throws SpiceError(:pointonzaxis) if the point is on the z axis.

Examples

The two Jacobians at one point are inverses:

julia> dlatdr(1, 1, 0) * drdlat(reclat([1, 1, 0])...) ≈ ident()
true

See also drdlat, reclat.
