Vectors and matrices

Rules for all mathematics calls

These rules hold for every call on the Mathematics pages:

  • No kernel is needed, except by recpgr, pgrrec, drdpgr, dpgrdr and xfmsta, which read the radii of a body.
  • Integer components are converted to Float64.
  • A sum of products is evaluated term by term in index order, as in CSPICE, so a Float64 input gives the result of CSPICE. The * of StaticArrays can round differently.
  • An input of the wrong size throws SpiceError(:badarg).

Almanac.vnorm — Function
vnorm(v1)

Return the Euclidean norm of a vector of 3 elements, as vnorm_c of CSPICE.

The components are divided by the one largest in magnitude before they are squared, so the squares do not overflow or underflow. The result is zero only for the zero vector.

Throws SpiceError(:badarg) if v1 does not have 3 elements.

Examples

julia> vnorm([3, 4, 0])
5.0

julia> isfinite(vnorm([3e200, 4e200, 0]))
true

See also vhat, unorm, vdist, vnormg.

Almanac.frame — Function
frame(x) -> (x̂, y, z)

Return a right-handed orthonormal frame whose first axis is along x, as frame_c of CSPICE.

x̂ is the unit vector along x, and y and z complete the frame; the three are SVector{3} values. y[i] == 0 for the first index i of the smallest abs(x̂[i]). The zero vector gives the axes of the input frame. CSPICE overwrites its argument x with x̂; this call does not change x.

Throws SpiceError(:badarg) if x does not have 3 elements.

Examples

julia> frame([0, 0, 2]) == ([0, 0, 1], [0, -1, 0], [1, 0, 0])
true

See also twovec.

Almanac.invstm — Function
invstm(mat) -> SMatrix{6,6}

Return the inverse of a state transformation matrix, as invstm_c of CSPICE.

A state transformation [R 0; dR R], with a rotation R and its time derivative dR, as sxform returns it, has the inverse [R' 0; dR' R']. The call transposes each of the four 3 by 3 blocks of mat in its place. It does not check that mat is a state transformation.

Throws SpiceError(:badarg) if mat is not 6 by 6.

Examples

julia> x = eul2xf([0.1, 0.2, 0.3, 1e-3, 2e-3, 3e-3], 3, 1, 3);

julia> invstm(x) * x ≈ [i == j for i in 1:6, j in 1:6]
true

See also xpose6, invert.

Almanac.invert — Function
invert(m) -> SMatrix{3,3}

Return the inverse of a 3 by 3 matrix, as invert_c of CSPICE.

A matrix whose determinant is below 1e-16 in absolute value counts as singular: the result is then the zero matrix, and no error is thrown.

Almanac.invort — Function
invort(m) -> SMatrix{3,3}

Return the inverse of a 3 by 3 matrix whose columns are orthogonal and have any non-zero length, as invort_c of CSPICE.

The result is the transpose with each row divided by the squared length of the matching column. The columns are not checked to be orthogonal.

Throws SpiceError(:zerolengthcolumn) if a column is zero. Throws SpiceError(:columntoosmall) if the length of a column has no finite reciprocal. Throws SpiceError(:badarg) if m is not 3 by 3.

Vectors and matrices of any dimension

The g calls take no dimension argument: the arguments give the dimension. A call whose array arguments are all static gives a static result, and does not allocate; a call with any other array argument gives a Vector or a Matrix that counts from 1, with the same elements. Two vectors must have equal length.

ducrss(s1, s2) -> SVector{6}

Return the unit vector along the cross product of the positions of two states, followed by its time derivative, as ducrss_c of CSPICE.

Each state is scaled by its largest position component first. Parallel positions give a zero unit vector. If a scaled velocity or a product of the scaled states is not finite, the derivative part is NaN; CSPICE returns numbers without meaning there.

Throws SpiceError(:badarg) if a state does not have 6 elements.

See also ucrss, dvcrss, dvhat.

Almanac.dvnorm — Function
dvnorm(state)

Return the time derivative of the norm of the position of state, as dvnorm_c of CSPICE. A zero position gives 0.

Throws SpiceError(:badarg) if state does not have 6 elements.

Almanac.dvsep — Function
dvsep(s1, s2)

Return the time derivative of the angle between the positions of two states, in rad/s for velocities per second, as dvsep_c of CSPICE. Parallel positions, or a zero position, give 0.

Throws SpiceError(:numericoverflow) if the size of the result is above 1e308, and SpiceError(:badarg) if a state does not have 6 elements.

See also vsep.
