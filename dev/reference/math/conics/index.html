Conic elements and two-body propagation

Almanac.conics — Function
conics(elts, et) -> SVector{6}

Return the state at the epoch et of a body on the conic orbit with the elements elts, as conics_c of CSPICE.

IndexNameMeaning
1rpperifocal distance
2ecceccentricity
3incinclination, rad
4lnodelongitude of the ascending node, rad
5argpargument of periapsis, rad
6m0mean anomaly at the epoch t0, rad
7t0epoch of the elements
8mugravitational parameter of the central mass

The units must be consistent, for example km, seconds past J2000 TDB for et and t0, and km³/s². The elements are converted to Float64. et can be a ForwardDiff.Dual or an Almanac.Taylor number (the truncated Taylor series of spkder), and the packages of Differentiate with other AD packages differentiate with respect to a Float64 et.

Throws:

  • SpiceError(:badeccentricity) if ecc < 0.
  • SpiceError(:badperiapsevalue) if rp <= 0.
  • SpiceError(:badgm) if mu <= 0.
  • SpiceError(:dtoutofrange) if et - t0 is so large that the solution would overflow. The bound depends on the orbit, as in CSPICE.
  • SpiceError(:badarg) if elts does not have 8 elements.

Examples

A circular orbit with unit radius and mu = 1, a quarter period after the epoch:

julia> conics([1, 0, 0, 0, 0, 0, 0, 1], pi / 2) ≈ [0, 1, 0, -1, 0, 0]
true

See also oscelt, prop2b.

Almanac.oscelt — Function
oscelt(state, et, mu) -> SVector{8}

Return the osculating conic elements (rp, ecc, inc, lnode, argp, m0, t0, mu) of a state, as oscelt_c of CSPICE.

state is the position and the velocity at the epoch et, relative to a mass with the gravitational parameter mu. The table in conics defines the elements; t0 is et. The angles are in radians: inc in [0, pi], and lnode and argp in [0, 2 pi). m0 is in [0, 2 pi) for an ellipse.

As in CSPICE, an eccentricity within 1e-10 of 1 becomes 1. An inclination within 1e-10 of 0 or pi becomes that value, and lnode is then 0.

Throws SpiceError(:nonpositivemass) if mu <= 0. Throws SpiceError(:degeneratecase) if the position or the velocity is zero or if they are parallel. Throws SpiceError(:badarg) if state does not have 6 elements.

Examples

The apoapsis of an orbit with mu = 1, semi-major axis 4/3 and eccentricity 0.5:

julia> round.(Tuple(oscelt([0, 2, 0, -0.5, 0, 0], 0, 1)); digits=6)
(0.666667, 0.5, 0.0, 0.0, 4.712389, 3.141593, 0.0, 1.0)

See also oscltx, conics.

Almanac.eqncpv — Function
eqncpv(et, epoch, eqel, rapol, decpol) -> SVector{6}

Return the state at the epoch et (seconds past J2000 TDB) of a body whose orbit is given by equinoctial elements with the rates of the node and of the periapsis, as eqncpv_c of CSPICE.

eqel holds the elements at epoch (seconds past J2000 TDB):

IndexMeaning
1semi-major axis a, km
2, 3h = e sin(argp + node), k = e cos(argp + node)
4mean longitude argp + node + M0, rad
5, 6p = tan(inc/2) sin(node), q = tan(inc/2) cos(node)
7rate of the longitude of periapsis, rad/s
8mean longitude rate, rad/s
9rate of the longitude of the ascending node, rad/s

The elements are relative to the equator of a pole with the right ascension rapol and the declination decpol (rad), given in the frame of the result. The x axis of that equator, from which the longitudes count, is at the right ascension rapol + pi/2. This is the model of SPK type 17. The result is in km and km/s. The arguments other than et are converted to Float64; et can be a ForwardDiff.Dual or an Almanac.Taylor number (the truncated Taylor series of spkder). A zero mean longitude rate gives a velocity of NaN, as in CSPICE.

Throws SpiceError:

  • :badsemiaxis if a <= 0;
  • :eccoutofrange if sqrt(h² + k²) > 0.9;
  • :eccoutofbounds if not, but h² + k² >= 0.81 (an eccentricity of 0.9 to rounding);
  • :badarg if eqel does not have 9 elements.

Examples

A circular equatorial orbit (pole on the z axis) a quarter period after the epoch:

julia> n = 1e-3; s = eqncpv(pi / 2 / n, 0, [7000, 0, 0, 0, 0, 0, 0, n, 0], -pi / 2, pi / 2);

julia> s ≈ [0, 7000, 0, -7, 0, 0]
true

See also conics.

kpsolv(evec) -> Float64

Almanac.prop2b — Function
prop2b(gm, pvinit, dt) -> SVector{6}

Return the state of a body at the time dt after the state pvinit, for two-body motion about a mass with the gravitational parameter gm, as prop2b_c of CSPICE.

The units must be consistent, for example km, km/s, seconds and km³/s². gm and pvinit are converted to Float64. dt can be a ForwardDiff.Dual or an Almanac.Taylor number (the truncated Taylor series of spkder); the result then holds the derivatives with respect to dt. The reverse-mode packages of Differentiate with other AD packages take the same derivative with respect to a Float64 dt.

Throws:

  • SpiceError(:nonpositivemass) if gm <= 0.
  • SpiceError(:zeroposition) or SpiceError(:zerovelocity) if that part of pvinit is zero.
  • SpiceError(:nonconicmotion) if the position and the velocity are parallel.
  • SpiceError(:dtoutofrange) if dt is so large that the solution would overflow. The bound depends on the orbit, as in CSPICE.
  • SpiceError(:badarg) if pvinit does not have 6 elements.

Examples

A quarter of a circular orbit with unit radius and gm = 1:

julia> prop2b(1, [1, 0, 0, 0, 1, 0], pi / 2) ≈ [0, 1, 0, -1, 0, 0]
true

See also conics, oscelt.

Almanac.stmp03 — Function
stmp03(x) -> (c0, c1, c2, c3)

Return the Stumpff functions ck(x) = sum((-x)^j / (2j + k)!, j = 0:∞) for k = 0:3, as stmp03 of SPICELIB. CSPICE has no C wrapper for it.

c0 = 1 - x * c2 and c1 = 1 - x * c3 hold to rounding. For x > 0, c0 is cos(sqrt(x)) and c1 is sin(sqrt(x)) / sqrt(x).

Throws SpiceError(:valueoutofrange) if x <= -(log(2) + log(floatmax(Float64)))^2, about -5.05e5, where c0 would overflow.

Examples

julia> stmp03(0)
(1.0, 1.0, 0.5, 0.16666666666666666)

See also prop2b.

Polynomials and interpolation

A Chebyshev expansion, a sum of Chebyshev polynomials of the first kind, is given by its coefficients and by x2s = [midpoint, radius] of its interval, as in an SPK segment of type 2 or 3. A table for interpolation is given by its abscissas, or by the first abscissa and the step of an equally spaced table; a Hermite table holds the value and the derivative at each abscissa, in this order.

Almanac.chbval — Function
chbval(cp, x2s, x) -> p

Return the value at x of the Chebyshev expansion with the coefficients cp, as chbval_c of CSPICE.

The expansion is p(x) = sum(cp[k] * T_{k-1}(s)) with s = (x - x2s[1]) / x2s[2]: x2s holds the midpoint and the radius of the interval of the expansion. The degree is length(cp) - 1. A value of x outside the interval is not an error. As in CSPICE, x2s[2] is not checked: 0 gives NaN, and a negative radius is used as given.

Throws SpiceError(:invaliddegree) if cp is empty. Throws SpiceError(:badarg) if x2s does not have 2 elements.

Examples

T_0 + 2 T_1 + 3 T_2 at s = 0.5, where T_2(s) = 2s² - 1:

julia> chbval([1, 2, 3], [0, 1], 0.5)
0.5

See also chbint, chbder, chbigr.

Almanac.rquad — Function
rquad(a, b, c) -> (root1, root2)

Return the roots of the quadratic equation a x² + b x + c = 0, as rquad_c of CSPICE. Each root is an SVector of its real part and its imaginary part.

root1 is (-b + sqrt(b² - 4ac)) / 2a and root2 the root with the minus sign. If a == 0, both are the root -c / b of the linear equation. The coefficients are divided by the largest of their magnitudes first, unless that makes one of them zero.

Throws SpiceError(:degeneratecase) if a == b == 0.

Examples

julia> rquad(1, 0, -4)
([2.0, 0.0], [-2.0, 0.0])

julia> rquad(1, 0, 4)
([-0.0, 2.0], [-0.0, -2.0])

See also diags2.

Almanac.diags2 — Function
diags2(symmat) -> (d, r)

Return the diagonal matrix d and the rotation r that diagonalize the symmetric 2 by 2 matrix symmat, so that d = r' * symmat * r, as diags2_c of CSPICE.

Only the upper triangle of symmat is read. The columns of r are unit eigenvectors, and d[i, i] is the eigenvalue of column i. Of the rotations that diagonalize symmat, r has an angle of the smallest magnitude, so a diagonal symmat gives the identity. If symmat[1, 1] == symmat[2, 2], the angle is ±pi/4 and d[2, 2] is the larger eigenvalue.

Throws SpiceError(:badarg) if symmat is not 2 by 2.

Examples

julia> d, r = diags2([2 1; 1 2]);

julia> round.(d; digits=12) == [1 0; 0 3]
true

See also rquad.

Doubles as hexadecimal strings

A double is written as hexadecimal digits of a mantissa in [1/16, 1) and an exponent of

Almanac.dp2hx — Function
dp2hx(number) -> String

Return the base 16 string of number, as dp2hx_c of CSPICE.

The string is an optional minus sign, the hexadecimal digits of the mantissa in [1/16, 1), a caret ^ and the exponent of 16 in hexadecimal, as in "2A^3" for 672. The digits are exact: every double has a finite string. Zero, and NaN as in CSPICE, give "0^0". hx2dp converts the string back.

Throws SpiceError(:valueoutofrange) for an infinite number; dp2hx_c does not return for it.

Examples

julia> dp2hx(672.0), dp2hx(-11.0), dp2hx(0.1)
("2A^3", "-B^1", "1999999999999A^0")

Almanac.hx2dp — Function
hx2dp(str) -> Float64

Return the double of the base 16 string str, as hx2dp_c of CSPICE.

The string has the form that dp2hx writes: an optional sign, at most 31 hexadecimal digits of the mantissa, a caret ^ and the exponent of 16 in hexadecimal with an optional sign. Letter case is ignored, and blanks before and after the string and after the caret are skipped. The digits are read as a fraction: "2A^3" is (2/16 + 10/16²)·16³ = 672.

Throws SpiceError(:emptystring) if str is empty. Throws SpiceError(:badnumber), with the message of hx2dp_c, for a blank string, a character out of place, more than 31 mantissa digits, a missing caret or exponent, an exponent outside the 32-bit integers, or a result too large in magnitude for a double.

Examples

julia> hx2dp("2A^3"), hx2dp("-B^1"), hx2dp(dp2hx(0.1)) == 0.1
(672.0, -11.0, true)
