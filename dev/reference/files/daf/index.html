DAF files and SPK segments

SPK, CK and binary PCK files are DAF (double precision array file) files. A file handle is a DAFHandle object, not an integer. The calls that continue an array search or an array being added (daffna, daffpa, dafgs, dafgn, dafws, dafrs, dafrn, dafada, dafena) take the handle, which the C calls do not, because the handle holds the state of the search.

The identifier of an SPK or CK segment (segid, ident) is the name of its DAF array, which dafgn returns.

DAF files

Almanac.DAFHandle — Type
DAFHandle

An open DAF file. It replaces the integer handle of CSPICE.

dafopr, dafopw, dafonw, spkopn, spkopa, ckopn and pckopn return a handle of a file. dafops, spkops, ckops and pckops return a handle that keeps the bytes in memory, with no file; furnsh loads it. Close it with dafcls, spkcls, ckcls, pckcls or close; isopen(handle) tells whether it is open.

The handle holds the state of the array search (dafbfs, daffna, dafbbs, daffpa) and of the array that is being added (dafbna, dafada, dafena), which CSPICE keeps in global tables. One handle is not safe for concurrent use: tasks that share a handle must hold a lock around every call. A file that a handle has open cannot be opened for write by another handle (SpiceError(:fileopenconflict)).

A call on a closed handle throws SpiceError(:dafnosuchhandle), except the close calls, which do nothing. A write call on a handle open for reading throws SpiceError(:dafinvalidaccess). A write call puts its bytes on disk before it returns, except spk14b and spk14a, whose data spk14e writes; a write call that throws for an invalid input does not change the file.

Almanac.dafopr — Function
dafopr(path) -> DAFHandle

Open the DAF file path for reading and return its handle, as dafopr_c.

The file can have either byte order. No array search is begun. Close the handle with dafcls.

Throws SpiceError:

  • :emptystring if path is empty, :blankfilename if it holds only blanks;
  • :filenotfound if the file does not exist;
  • :filereadfailed if the file is shorter than one record (1024 bytes);
  • :filarchmismatch if the file is a DAS file, :unknownfilarc if it is neither a DAF nor a DAS file (a text kernel, for example);
  • :ftpxfererror if the file was damaged by a transfer in text mode;
  • :unknownbff if the binary file format (the number format that the file record names) is not known, :unsupportedbff if it is VAX-GFLT or VAX-DFLT;
  • :dafinvalidparams if the summary format in the file record is not valid;
  • :fileopenfailed if the process may not read the file.

Examples

Write an SPK file with one segment, then search it as a DAF:

julia> path = joinpath(mktempdir(), "example.bsp");

julia> h = spkopn(path, "example SPK");

julia> cdata = [[1.0, 0.5, 2.0, 0.0, 3.0, 0.0]];

julia> spkw02(h, 499, 4, "J2000", 0.0, 100.0, "mars", 100.0, cdata, 0.0)

julia> spkcls(h)

julia> h = dafopr(path);

julia> dafbfs(h)

julia> daffna(h)
true

julia> dc, ic = dafus(dafgs(h), 2, 6)   # see dafgs for the meaning of the components
([0.0, 100.0], [499, 4, 1, 2, 385, 396])

julia> dafgn(h)
"mars"

julia> dafgda(h, ic[5], ic[5] + 1)      # midpoint and radius of the first record, s
2-element Vector{Float64}:
 50.0
 50.0

julia> daffna(h)
false

julia> dafcls(h)

See also dafopw, dafbfs, dafgda, dafec, getfat.

Almanac.dafopw — Function
dafopw(path) -> DAFHandle

Open the existing DAF file path for writing, as dafopw_c, to add arrays or comments.

The file must have the native byte order, and no other handle may have it open. dafopr can still open the file for read, and a kernel that furnsh loaded does not count as open; CSPICE refuses both. A context that loaded the file sees the arrays added later only after it loads the file again.

Throws the SpiceError kinds of dafopr, :unsupportedbff if the file has the other byte order, :fileopenconflict if another handle has the file open, and :fileopenfail if the file cannot be opened for update.

Almanac.dafonw — Function
dafonw(path, ftype, nd, ni, ifname, resv) -> DAFHandle

Create the DAF file path and open it for writing, as dafonw of SPICELIB.

  • ftype: the file type, for example "SPK". Four characters are stored.
  • nd, ni: the numbers of doubles and of integers in an array summary.
  • ifname: the internal file name. 60 characters are stored.
  • resv: the number of reserved records, which hold the comments, 1000 characters in each.

The file is on disk when the call returns: the file record, resv comment records with an empty comment area, one empty summary record and one name record, byte for byte as CSPICE writes them. The byte order is the native one. An existing file is never replaced.

Throws SpiceError, in this order:

  • :blankfiletype if ftype is blank, :illegalcharacter if it has a character that is not printable;
  • :dafinvalidparams unless 0 <= nd <= 124, 2 <= ni <= 250 and nd + (ni + 1) ÷ 2 <= 125;
  • :dafnoresv if resv < 0;
  • :blankfilename if path is blank;
  • :fileopenfail if the file exists or cannot be created.

See also spkopn, ckopn, dafbna, dafcls.

Almanac.dafops — Function
dafops(ftype, nd, ni, ifname, resv) -> DAFHandle

Open a new DAF in memory for writing: dafonw without a file. This call has no CSPICE counterpart.

The handle takes every read and write call of a DAF handle. save_kernel(handle, path) -> Nothing

Write the in-memory DAF handle (from spkops, ckops, pckops or dafops) to the new file path: the bytes that the same write calls put in a file made by spkopn. Almanac.dafps — Function
dafps(dc, ic) -> Vector{Float64}

Pack the double precision components dc and the integer components ic of an array summary into length(dc) + (length(ic) + 1) ÷ 2 doubles, as dafps_c.

Almanac.dafgda — Function
dafgda(handle, first, last) -> Vector{Float64}

Return the doubles at the DAF addresses first:last, as dafgda_c. Addresses start at 1, as in CSPICE.

Two results differ from CSPICE:

  • If the file ends inside its last record, the doubles of that record that the file holds are returned. CSPICE returns zeros for the whole record.

Almanac.dafbna — Function
dafbna(handle, sum, name) -> Nothing

Begin a new array in the DAF file of handle, as dafbna of SPICELIB.

sum is the packed summary (dafps); dafena sets its two address components. name is the array name, cut or padded to 8 * (nd + (ni + 1) ÷ 2) characters (40 for an SPK or a CK file). Add the data with dafada and end the array with dafena. An array that was begun before and not ended is abandoned, as in CSPICE.

Throws SpiceError(:dafinvalidparams) if sum has fewer doubles than a summary of the file.

julia> dafada(h, [10.0, 20.0, 30.0])

julia> dafena(h)

julia> dafbfs(h)

julia> daffna(h)
true

julia> dafus(dafgs(h), 2, 6)

julia> dafcls(h)

Almanac.dafac — Function
dafac(handle, lines) -> Nothing

Append the comment lines lines to the comment area of the DAF file, as dafac_c.

A line can have any length; trailing blanks are not stored. If the reserved records do not have room, records are added and the data of the file move. Every address that was read from a summary before the call is then stale, and a search on the handle is at its end: begin a new search. The comments are on disk when the call returns.

Throws SpiceError:

  • :invalidargument if lines is empty;
  • :illegalcharacter if a line has a character outside the printable ASCII codes 32 to 126;
  • :dafnewconflict if an array is begun and not ended on the handle.

A call that throws does not change the file.

julia> dafac(h, ["first line", "second line   "])

SPK segments

A loaded file has no handle, so spksfs returns the path of the file, which spkpvn takes with the same context.

Almanac.spksfs — Function
spksfs([ctx,] body::Integer, et) -> Union{Nothing,Tuple{String,Vector{Float64},String}}

Return (file, descr, ident) for the loaded SPK segment of the highest priority for body at et, as spksfs_c, or nothing if no loaded segment of body covers et.

  • file: the path of the loaded SPK file as it was passed to furnsh (the path that kdata gives). It takes the place of the handle of CSPICE: pass it to spkpvn with the same context, or open the file with dafopr.
  • descr: the descriptor of the segment, 5 doubles; spkuds unpacks it.
  • ident: the segment identifier, without trailing blanks.

et is in seconds past J2000 TDB. A segment covers its first and its last epoch. The priority is that of CSPICE: a file loaded later comes first, and in one file a later segment comes first.

Throws SpiceError(:noloadedfiles) if no SPK file is loaded.

Examples

julia> path = joinpath(mktempdir(), "example.bsp");

julia> h = spkopn(path, "example SPK");

julia> spkw02(h, 499, 4, "J2000", 0.0, 100.0, "mars", 100.0, [[1.0, 0.5, 2.0, 0.0, 3.0, 0.0]], 0.0)

julia> spkcls(h)

julia> ctx = SpiceContext();

julia> furnsh(ctx, path)

julia> file, descr, ident = spksfs(ctx, 499, 50.0);

julia> ident, spkuds(descr)
("mars", (499, 4, 1, 2, 0.0, 100.0, 385, 396))

julia> ref, state, center = spkpvn(ctx, file, descr, 100.0);

julia> ref, state == [1.5, 2.0, 3.0, 0.01, 0.0, 0.0], center
(1, true, 4)

julia> spksfs(ctx, 499, 200.0) === nothing
true

See also spksub, spkobj, spkcov.

Almanac.spkpvn — Function
spkpvn([ctx,] handle::DAFHandle, descr, et) -> (ref, state, center)
spkpvn([ctx,] file::AbstractString, descr, et) -> (ref, state, center)

Return the state of the target of one SPK segment relative to the center of the segment at et, as spkpvn_c.

The segment has the descriptor descr (5 doubles, from dafgs or spksfs). It is in the file of handle, or in the file with the path file that is loaded in the context (the file of spksfs; it must be the same string, because the path is not normalized). ref is the ID of the frame of the segment and center the NAIF ID of its center, both Int. state is an SVector{6}: position in km, then velocity in km/s, in the frame ref. et is in seconds past J2000 TDB.

The context gives the leap seconds that a segment of type 10 needs; the form with a handle reads nothing else from it. With a handle, a call reads the directory and one record of a segment of type 2 or 3, and the whole segment of another type.

Throws SpiceError:

  • :nosuchhandle if no SPK file with the path file is loaded in the context, and :dafnosuchhandle if handle is closed;
  • :badarg if et is not finite;
  • :spktypenotsupp if the data type is not one of CSPICE version N0067, at any et;
  • :spkrectoolarge for a segment of type 14 whose series have more than 32 coefficients, as CSPICE, whose record buffer has 198 doubles;
  • :timeoutofbounds if et is outside the coverage of descr, for every type but 15 and 17, whose single set of elements is propagated to et as CSPICE does (CSPICE checks only some types);
  • :dafnegaddr, :dafbeggtend or :filereadfailed if the addresses of descr are not a range in the file;
  • the kinds of the evaluators of CSPICE for the values that they refuse: type 5 those of prop2b; type 15 :malformedsegment, :badlatusrectum, :badeccentricity, :nonpositivemass, :badvector, :badradius, :badinitstate; type 17 :malformedsegment, :badsemiaxis, :badeccentricity, :eccoutofbounds; type 18 :toofewstates, :notsupported, :invalidvalue; type 19 :notsupported, :invalidvalue; type 20 :invalidcount; type 21 :difflinetoolarge, :zerostep;
  • :baddaf if the data of the segment do not form a valid segment in a way that CSPICE does not check;
  • :noleapseconds for a segment of type 10 and a context without leap seconds.

See also spksfs for an example, spkuds.

Almanac.spksub — Function
spksub(handle, descr, ident, start, stop, newh) -> Nothing

Write the part of an SPK segment that covers the interval [start, stop] as a new segment of another SPK file, as spksub_c.

  • handle, descr: the file that holds the source segment (dafopr) and the descriptor of the segment (dafgs, spksfs).
  • ident: the identifier of the new segment.
  • start, stop: the coverage of the new segment, seconds past J2000 TDB.
  • newh: the DAFHandle of the new file, open for writing (spkopn, spkopa).

The new segment holds the records of the source that the evaluation in [start, stop] needs: the data that spksub_c writes from the same source, double for double. It is on disk when the call returns.

In [start, stop] the new segment gives the states of the source segment, within rounding for the types 8 and 12. For type 20 the states differ from those of the source by up to about 3e-8 relative, in CSPICE as here, because the new segment stores its first epoch as a Julian date.

For the types other than 14, an ident of more than 40 characters is cut to 40, as in CSPICE. A segment of type 14 is written with spk14b, so ident must be a valid identifier, start must be before stop, and the frame of the source must be an inertial frame of the built-in table (IDs 1 to 21).

Throws SpiceError:

  • :emptystring if ident is empty;
  • :spknotasubset unless first <= start <= stop <= last, where [first, last] is the coverage of descr;
  • :spktypenotsupp if the data type is not one of CSPICE N0067;
  • for type 14: :spkrectoolarge if the degree of the polynomials is above 20, :invalidrefframe if the frame is not inertial, :baddescrtimes if start == stop, and the error kinds of spk14b for the identifier;
  • :invalidvalue (type 18), :notsupported (type 19) for an unknown subtype, and :spkstructureerror for a type 19 segment whose structure is damaged, or where the block of 100 epochs in which the search for stop ends begins after stop, a case in which CSPICE stops the process;
  • the error kinds of dafbna and dafgda if a handle is closed, newh is not open for writing, or the addresses of descr are not in the file.

A call that throws writes nothing and leaves no array begun on newh.

Examples

julia> dir = mktempdir();

julia> h = spkopn(joinpath(dir, "source.bsp"), "source");

julia> cdata = [[25.0, 0.25, 50.0, 0.0, 75.0, 0.0] for _ in 1:4];   # four records of 25 s

julia> spkw02(h, -9, 399, "J2000", 0.0, 100.0, "four records", 25.0, cdata, 0.0)

julia> spkcls(h)

julia> src = dafopr(joinpath(dir, "source.bsp")); dafbfs(src); daffna(src);

julia> newh = spkopn(joinpath(dir, "part.bsp"), "part");

julia> spksub(src, dafgs(src), "records 2 and 3", 30.0, 60.0, newh)

julia> spkcls(newh); dafcls(src)

julia> h = dafopr(joinpath(dir, "part.bsp")); dafbfs(h); daffna(h);

julia> spkuds(dafgs(h))
(-9, 399, 1, 2, 30.0, 60.0, 385, 404)

julia> dafcls(h)
